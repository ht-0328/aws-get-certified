# 練習問題の結果

AWS Skill Builder の公式練習問題などを解いた結果を、試験ごとのフォルダに置きます。

```
practice-results/
├── README.md
└── clf-c02/                      試験ごと（clf-c02, saa-c03 …）
    ├── 2026-10-23-skill-builder-official-practice-set-attempt1.html   結果ページ（Git に入れない）
    └── 2026-10-23-skill-builder-official-practice-set-attempt1.md     その回のまとめ
```

## ファイル名

`<解いた日>-<出どころ>-<問題セット>-attempt<回数>.<拡張子>`

- 解いた日：`2026-10-23` のように西暦から
- 出どころ：`skill-builder` など
- 問題セット：`official-practice-set`（公式練習問題 20問）など
- 回数：同じ問題セットを解いた回数

## 置くもの

- **.html**：Skill Builder の結果ページを「Web ページ、完全」で保存したもの。氏名・メールアドレスを含むため、`.gitignore` で Git には入れない。中身は編集しない。
- **.md**：その回のまとめ。点数、不正解の内訳（問われたこと・正解・選んだもの・原因・該当する章）、分かったこと、サイトに反映したこと。問題文をそのまま書き写さない。
