1. どの資格から受ける？

AWS の資格は、むずかしさで4段階に分かれています。はじめての人は一番下の「クラウドプラクティショナー」から受けるのがおすすめです。

専門知識（Specialty）

セキュリティ・機械学習など、特定の分野を深く

プロフェッショナル（Professional）

大きく複雑なシステムの設計

アソシエイト（Associate） ← 2つ目のおすすめ

ソリューションアーキテクト アソシエイト（SAA）：AWS でシステムを設計する力

基礎（Foundational） ← まずはここ

クラウドプラクティショナー（CLF）：AWS とクラウドの基本

下から上へ。このサイトは CLF の範囲を中心に、SAA で必要になる内容もふくめています。
各章の CLFSAA は、どちらの試験向けの内容かの目印です。

4. 4週間の学習プラン（CLF の例）

1日1時間を目安にしたプランです。新しいことを読む日と復習する日を混ぜているのがポイントです（間隔反復）。

週新しく読む復習
1週目勉強法 → 第1章 → 第2章 → 第3章各章を1日後・3日後に手ぶら復習。毎日カード10分。
2週目第4章 → 第5章 → 第6章1週目の章の7日後復習。毎日カード。
3週目第7章 → 第8章 → 第9章2週目の章の7日後復習、1週目の14日後復習。
4週目公式の練習問題・模擬試験まちがえた問題の章だけ読み直し → 手ぶら復習。
🔬模擬試験も「思い出す練習」
問題を解くこと自体が、いちばん強い復習です（テスト効果）。AWS Skill Builder の公式練習問題（無料のものあり）は、本番に近い形なので必ずやりましょう。まちがえた問題は「なぜその答えなのか」を自分の言葉で説明できるまで復習します。

5. 問題の解き方のコツ

キーワード → サービスの対応を作る

AWS の問題は「問題文のキーワード」で答えが決まることが多いです。

問題文にこう書いてあったら答えの候補
「誰が・いつ・何をしたか（操作の記録）」CloudTrail
「サーバーを管理したくない」「イベントで動く」Lambda
「世界中のユーザーに速く配信」CloudFront
「ほぼ使わない古いデータを、いちばん安く保管」S3 Glacier Deep Archive
「中断されてもよい処理を、いちばん安く」スポットインスタンス
「AWS のセキュリティ・コンプライアンスの報告書」AWS Artifact

各章の 🎯試験に出るポイント がこの対応表になっています。

消去法を使う

  • まず明らかにちがう選択肢を消す（存在しないサービス、役割がまったくちがうサービス）。
  • 「いちばん安い」「いちばん運用の手間が少ない」など、問題文の条件のことばに線を引くつもりで読む。
  • 「2つ選べ」の問題は、選ぶ数をまちがえないように注意。
