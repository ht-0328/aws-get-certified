学習の順番

上から順に進めてください。各章の最後で「復習の記録」ボタンを押すと、次に復習する日がここに表示されます（1日後 → 3日後 → 7日後 → 14日後 → 30日後）。

復習のための道具

🃏 復習カード

問題を見て、答えを思い出してからめくるカード。覚えたカードは間をあけて出てきます。

📖 用語集

わからない言葉をすぐ調べられる辞書。すべての章の用語をまとめています。

🎯 試験ガイド

どの試験から受けるか、試験の形式、どこが何％出るか、当日までの計画。

このサイトの3つのルール

① 地図 → 細部

各章は「この章の地図」から始まります。全体を先につかんでから細かい話に入ります。

② 読むより思い出す

読み終わったら、ページを閉じて「手ぶら復習」。思い出す作業そのものが記憶を強くします。

③ 間をあけてくり返す

一気にやるより、日をあけて何度か。復習日はこのサイトが計算します。
