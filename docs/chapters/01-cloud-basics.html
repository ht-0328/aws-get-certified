1. クラウドとは何か

企業が業務システムを運用する方法として、従来は自社でサーバーを購入し、自社の施設に設置して運用する形態が一般的でした。これをオンプレミスと呼びます。

これに対しクラウド（クラウドコンピューティング）は、AWS のような事業者が保有するコンピューティング資源を、インターネット経由で、必要なときに必要な量だけ利用し、利用量に応じて料金を支払う形態です。

💡イメージで理解する

オンプレミスとクラウドの関係は、自家発電設備を持つことと電力会社から電気を購入することの関係に近いものです。自家発電では設備の購入費が先にかかり、保守や故障対応も自社で行う必要があります。電力会社から購入する場合は、設備の運用を事業者に任せ、使用量に応じた料金だけを支払います。

2. クラウドコンピューティングの6つの利点

AWS はクラウドコンピューティングの利点を6つに整理しています。試験でそのまま問われるため、6つすべてを挙げられるようにしてください。

#利点（公式の表現）意味
1固定費を変動費に変える設備への先行投資の代わりに、利用量に応じた費用を支払う。
固定費：利用量にかかわらず発生する費用。変動費：利用量に応じて増減する費用。
2規模の経済の恩恵を受けるAWS が膨大な数の利用者の需要を集約して調達・運用するため、単価が下がり、利用者は低い料金で利用できる。
規模の経済：生産・調達の規模が大きいほど、1単位あたりのコストが下がること。
3キャパシティの予測が不要になる必要な処理能力を事前に見積もらなくてよい。需要に応じて増減できるため、過剰投資や容量不足を避けられる。
キャパシティ：システムが処理できる量や容量。
4速度と俊敏性を向上させるIT リソースを数分で用意できるため、開発や検証のサイクルを短縮できる。
俊敏性（アジリティ）：変化に迅速に対応できる能力。
5データセンターの運用・保守への投資が不要になる施設・電源・空調・ハードウェアの管理を AWS に任せ、自社の事業に注力できる。
6数分で世界中に展開できる世界各地のリージョンにシステムを短時間で展開し、各地の利用者に低遅延でサービスを提供できる。
🔑覚え方：「変・規・予・速・保・世」

変動費化 ／ 規模の経済 ／ 予測不要 ／ 速度と俊敏性 ／ 保守不要 ／ 世界展開

前半3つはコスト・容量に関する利点、後半3つは速さ・運用・展開範囲に関する利点と分けて整理すると覚えやすくなります。

🎯試験での問われ方
  • 「初期投資を抑え、使用した分だけ支払いたい」→ 固定費を変動費に変える
  • 「需要が予測できない」「アクセス量の変動が大きい」→ キャパシティの予測が不要（伸縮性）
  • 「新しい国・地域ですぐにサービスを開始したい」→ 数分で世界中に展開できる

クラウドサービスは、事業者がどこまでを管理し、利用者がどこからを管理するかによって3つのモデルに分類されます。

4. AWS グローバルインフラストラクチャ

AWS のインフラストラクチャは、世界各地のデータセンターで構成されています。その配置には階層的な単位があり、試験で頻繁に問われます。

AZ-a

データセンター

データセンター

データセンター
エッジロケーション世界各地の主要都市に配置
（CloudFront などが利用）
1つのリージョンには、原則として3つ以上の AZ があります。各 AZ は物理的に離れた場所にあり、電源やネットワークも独立していますが、AZ 間は低遅延の専用回線で接続されています。
単位概要押さえるべき点
リージョン
Region		AWS が拠点を置く地理的な地域（東京、大阪、バージニア北部など）リージョン同士は互いに独立している。データは利用者が明示的に移動・複製しない限り、他のリージョンへ移動しない。
アベイラビリティーゾーン（AZ）
Availability Zone		リージョン内にある、1つ以上のデータセンターから成る独立した区画複数の AZ にシステムを分散配置（マルチ AZ 構成）すると、1つの AZ に障害が起きても稼働を継続できる。これにより高可用性を実現する。
エッジロケーション
Edge Location		利用者の近くに配置された小規模な拠点CloudFront（コンテンツ配信）や Route 53（DNS）が利用する。コンテンツをキャッシュして低遅延で配信する。

リージョン選択の4つの基準

🔑覚え方：「法・地・サ・価」
  1. 法令・規制への準拠（コンプライアンス）：データを国内に保管する義務がある場合、選べるリージョンは限定される。
    コンプライアンス：法令や業界規制、社内規程を遵守すること。
  2. 地理的な近さ（レイテンシー）：利用者に近いリージョンほど応答が速い。
    レイテンシー：要求を送ってから応答が返るまでの遅延時間。
  3. サービスの提供状況：新しいサービスは一部のリージョンでのみ提供されている場合がある。
  4. 価格：同じサービスでも、リージョンによって料金が異なる。
⚠️間違えやすい点

リージョン選択の基準として適切でないものを選ばせる問題がよく出題されます。「AZ の数」や「サポートプランの種類」は、通常リージョン選択の基準には含まれません。上記の4つを正確に挙げられるようにしてください。

オンプレミスとクラウドの違いを説明してください。
オンプレミスは設備を自社で保有・設置・管理する形態。クラウドは事業者の資源をインターネット経由で必要な分だけ利用し、従量課金で支払う形態で、設備の運用は事業者が担う。
クラウドコンピューティングの6つの利点を挙げてください。
①固定費を変動費に変える ②規模の経済の恩恵 ③キャパシティの予測が不要 ④速度と俊敏性の向上 ⑤データセンターの運用・保守への投資が不要 ⑥数分で世界中に展開（変・規・予・速・保・世）
IaaS・PaaS・SaaS の違いと、AWS における IaaS・PaaS の代表例は何ですか。
利用者が管理する範囲が異なる。IaaS は OS 以上を利用者が管理（例：EC2）、PaaS はアプリケーションとデータのみ管理（例：Elastic Beanstalk）、SaaS は完成したソフトウェアを利用するだけ。
リージョン、AZ、エッジロケーションの関係を説明してください。
リージョンは地理的な地域で、その中に物理的に離れた複数の AZ（1つ以上のデータセンターから成る区画）がある。エッジロケーションは利用者の近くの小規模拠点で、CloudFront や Route 53 が利用する。
システムの可用性を高めるには、AZ をどのように使いますか。
複数の AZ に分散配置する（マルチ AZ 構成）。1つの AZ に障害が発生しても、他の AZ で稼働を継続できる。
リージョンを選択する際の4つの基準は何ですか。
コンプライアンス（法令・規制）、レイテンシー（利用者との距離）、サービスの提供状況、料金（法・地・サ・価）。
