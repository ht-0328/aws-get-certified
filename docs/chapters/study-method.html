覚えて、忘れない勉強法
このサイトの使い方

AWS の試験は「覚えること」がとても多い試験です。だからこそ、やみくもに読むのではなく、脳の仕組みに合った覚え方をします。このページでは、その方法と、このサイトのどこで何をすればいいかを説明します。

🗺️このページの地図（先に全体を見る）
  1. 記憶は「入れる → 保つ → 出す」の3ステップ
  2. 人は必ず忘れる → だから間隔をあけて復習する
  3. 読み返すより「手ぶらで思い出す」ほうが強い
  4. 覚えるための4つの道具（全体像・グループ分け・イメージ連結・頭字法）
  5. 1日の進め方と、このサイトのパーツの意味

1. 記憶は「入れる・保つ・出す」の3ステップ

「覚える」と一言でいっても、脳の中では次の3つのことが起きています。

📥
① 入れる

記銘。読む・聞く・図を見る。

→
🗄️
② 保つ

保持。時間がたっても消えないようにする。

→
📤
③ 出す

想起。試験本番で思い出す。

多くの人は①ばかりやって③の練習をしません。でも試験で必要なのは③です。

また、記憶にはいくつか種類があります。とくに大事なのが次の2つです。

📝ことばメモ
長期記憶
何日・何年も残る記憶。試験のために作りたいのはこれ。
意味記憶
「S3 はファイルの置き場所」のような知識そのものの記憶。単体だと忘れやすい。
エピソード記憶
「あのとき、こんな場面で…」という体験・お話の記憶。とても残りやすい。

このサイトでは、意味記憶（知識）をエピソード記憶（たとえ話・絵）にのせて覚えられるように、ほぼすべてのサービスに「たとえ話」と「AWS のアイコン図」をつけています。

2. 人は必ず忘れる → 間隔をあけて復習する

心理学者エビングハウスの実験では、覚えたことは1日たつと大きく抜け落ちることがわかっています（忘却曲線）。でも、忘れかけたタイミングで思い出すと、次に忘れるまでの時間がどんどん長くなります。

忘れかけたときに復習すると、記憶が長持ちする
赤：一度読んだだけ。緑：1日後・3日後・7日後…と間をあけて思い出したとき。
（形はイメージです）
🔬科学的な裏づけ：間隔反復（かんかくはんぷく）

同じ時間勉強するなら、一気に詰めこむより、日をあけて何回かに分けたほうが長く覚えていられる、という結果が多くの研究で出ています。これを分散学習や間隔反復といいます。

このサイトでは各章の最後に「復習の記録」ボタンがあり、押すと1日後 → 3日後 → 7日後 → 14日後 → 30日後と次の復習日を自動で出します。トップページに「今日復習する章」が出るので、それに従えばOKです。

3. 読み返すより「手ぶらで思い出す」

復習というと「ノートを読み返す」をしがちですが、それだとわかった気になるだけで、あまり残りません。いちばん効くのは、何も見ないで（手ぶらで）思い出すことです。

😐 効きにくい

・ページを何度も読み返す
・蛍光ペンで線を引く
・きれいにまとめノートを作る

😄 効く

・ページを閉じて、何があったか言ってみる
・問題を見て、答えを思い出してから確かめる
・人に説明するつもりで声に出す

🔬科学的な裏づけ：テスト効果・アクティブリコール

「思い出す」という作業そのものが記憶を強くします。これをテスト効果やアクティブリコール（自分から能動的に思い出すこと）といいます。思い出すのに少し苦労するくらいがちょうどいい、とされています。

このサイトでは各章に「手ぶら復習」のコーナーがあります。質問をクリックすると答えが出ますが、必ず先に頭の中で答えてから開いてください。

🙌 手ぶら復習の練習 （まず自分で答えてから開く）
記憶の3ステップを言えますか？
入れる（記銘）→ 保つ（保持）→ 出す（想起）
読み返しより効果が高い復習のやり方は？
何も見ずに思い出す「手ぶら復習」（アクティブリコール）。

4. 覚えるための4つの道具

道具① 全体像（地図）から入る

いきなり細かいことを覚えようとすると、どこに置けばいいかわからず、すぐ散らばります。各章の最初には「この章の地図」があります。まず地図を見て、「今どこを勉強しているか」をはっきりさせてから細部に入ります。本棚の棚の名前を先に決めてから、本をしまうイメージです。

道具② グループに分けて覚える（グループ分類法）

バラバラの10個より、3つのグループに分けた10個のほうがずっと覚えやすいです（心理学ではチャンク化と呼びます）。AWS のサービスは200以上ありますが、試験に出るのは「サーバー」「ストレージ」「データベース」「ネットワーク」…とグループにまとまります。このサイトの章立ても、そのグループのとおりです。

例：「データを置く場所」グループ
S3なんでも置ける倉庫
EBSサーバー専用のディスク
EFSみんなで使う共有フォルダ
3つまとめて「置き場所 3兄弟」として覚えると、試験で比べる問題に強くなります。

道具③ イメージ（絵・お話）でつなげる（イメージ連結法）

文字だけの知識は忘れやすいですが、絵や場面と結びつけると残りやすくなります。たとえば：

CloudFrontクラウドフロント
→「全国にあるコンビニ」。本社の倉庫（サーバー）まで行かなくても、近くのコンビニに商品（データ）が置いてあるから、すぐ手に入る。

このサイトでは AWS の実際のアイコンを使っているので、アイコンの形・色もイメージの手がかりになります（オレンジ＝サーバー系、緑＝ストレージ系、紫＝ネットワーク系、赤＝セキュリティ系など）。

道具④ 頭文字で覚える（頭字法）

並びを覚えるときは、頭文字をつないで1つの言葉にします。たとえば、AWS が「よい設計」の基準として決めている6つの項目：

🔑覚え方の例

AWS の「6つの柱」（Well-Architected）＝ 「運・セ・信・パ・コ・サ」（うん、せしんぱこさ）
運用上の優秀性／セキュリティ／信頼性／パフォーマンス効率／コスト最適化／サステナビリティ

各章の「🔑覚え方」ボックスにこうした覚え方を入れています。自分で作り直したほうが覚えやすければ、どんどん作り変えてください。自分で作った覚え方がいちばん強いです。

おまけ：自分の言葉で説明する

読み終わったら、「中学生に説明するなら？」と考えて声に出して説明してみてください。説明できないところ＝まだわかっていないところです。このサイトのたとえ話は、そのお手本にもなるように書いています。

5. 1日の進め方

順番やること目安
①トップページで「今日復習する章」を確認。あれば、その章の手ぶら復習だけやる（本文は読まない）5〜10分
②復習カードで、期限が来たカードを思い出す10分
③新しい章を1つ読む。地図 → 本文 → 図 → 覚え方30〜45分
④ページを閉じて手ぶら復習 → 「復習の記録」ボタンを押す10分

※わからない言葉にぶつかったら、点線のついた言葉をタップすると意味が出ます。用語集ページでまとめて探すこともできます。
