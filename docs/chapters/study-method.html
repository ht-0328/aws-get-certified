学習方法
記憶を定着させるための進め方と、本サイトの使い方

AWS 認定試験では、多数のサービスの役割と、似たサービスの使い分けを正確に記憶しているかが問われます。本サイトは、認知心理学の研究で効果が確認されている学習法に沿って構成しています。このページでは、その考え方と具体的な進め方を説明します。

1. 学習を始める前に決める3つのこと

どの学習法が最も効率的かは、状況によって変わります。教材や学習法を選ぶ前に、次の3点を明確にしてください。

項目決めること判断への影響
目的どの試験に合格するか（基礎の CLF か、設計力を問う SAA か）学習範囲と、求められる理解の深さが決まる
期限試験日まで何週間あるか期間が長ければ第1章から順に基礎を固める。2週間程度しかなければ、模擬試験と弱点分野の想起練習を優先する
現状用語の意味が分かる段階か、似たサービスを使い分けられる段階か前者なら本文の通読、後者なら想起練習と比較表の確認に時間を配分する

2. 記憶の3段階と、「分かる」と「思い出せる」の違い

「覚える」という行為は、脳の中では次の3つの段階に分けて考えられます。

① 記銘

情報を取り込む段階。読む、聞く、図を見る。

→
② 保持

取り込んだ情報を、時間がたっても失わずに保つ段階。

→
③ 想起

必要な場面で、記憶から情報を取り出す段階。

学習時間の大半を①に費やし、③をほとんど練習しないのはよくある失敗です。試験で求められるのは③です。

「見れば分かる」は「覚えている」ではない

テキストを見ながら「知っている」「理解できた」と感じることを再認、何も見ずに自分で情報を取り出せることを再生（想起）と呼びます。再認できても再生できるとは限らず、読み返しを繰り返すと、見覚えがあるだけで「覚えた」と判断してしまいがちです。

🔑確認の方法：閉じて答える

1つの節を読み終えたら、画面を閉じるか目を離して、「いま何について書かれていたか」を自分に問います。答えられた箇所、曖昧な箇所、まったく出てこない箇所がその場で区別でき、次に何を復習すべきかが明確になります。

📝用語の補足
作業記憶
情報を一時的に保持しながら処理するための記憶（ワーキングメモリ）。容量が小さく、別の作業をすると内容がすぐ失われる。読んだ直後に言えるのは、多くの場合この段階にとどまっている。
長期記憶
数日から数年にわたって保持される記憶。試験対策で作るべきなのはこれ。
意味記憶
「S3 はオブジェクトストレージである」のような、事実や知識の記憶。単独では定着しにくい。
エピソード記憶
特定の場面や経験と結びついた記憶。具体的な状況を伴うため、意味記憶より想起しやすいとされる。

本サイトでは、サービスの説明に具体的な利用場面や構成図を添えています。知識を具体的な状況と結びつけることで、想起の手がかりを増やすためです。

3. 読むときの5つの手順

本文を漫然と読むのではなく、次の5つを意識しながら読むと、1回の通読で残る内容が大きく変わります。

STEP 1予測する

読む前に「この章の全体像」と「読む前の問い」を確認し、答えを探すつもりで読む。

STEP 2短く言い換える

公式の説明をそのまま覚えず、一文で要約する。例：Auto Scaling＝需要に応じてインスタンス数を自動で増減する仕組み。

STEP 3図の上で動かす

構成図を見ながら、リクエストやデータがどの順に流れるかを頭の中でたどる。

STEP 4因果関係でつなぐ

「A が起きる → だから B が必要 → その結果 C になる」と、理由と結果の流れで整理する。

STEP 5自分の経験に結びつける

普段使っているアプリや自社の業務なら、どこで使われるかを考える。

🔬根拠：精緻化質問と自己説明

「なぜそうなるのか」を自分に問いながら読む方法（精緻化質問）や、読んだ内容を自分に説明しながら読む方法（自己説明）は、学習法の効果を比較した研究で、中程度以上の効果が認められています。

4. 読んだ後に思い出す4つの手順

本文を閉じた後は、大きな枠組みから細部へと順に取り出します。木にたとえると、幹から枝、枝から葉へと広げていく順序です。

STEP 1主題

「いまの節は一言でいうと何の話だったか」を答える。

STEP 2主要な要素

主題を構成するサービス名や、3〜4個の柱となる項目を挙げる。

STEP 3詳細

各要素の特徴、制約、使い分けの条件まで広げる。

STEP 4再構成

「〇〇とは何か」と質問されたと想定し、全体を自分の言葉で説明し直す。

各章末の「🧠 想起練習」の設問は、この順序を意識して並べています。

5. 負担の小さい想起練習

想起練習の重要性は分かっていても、白紙に書き出したり問題集を解いたりするのは負担が大きく、継続しにくいものです。次の3つは数秒から数分で行えるため、毎日の習慣にしやすい方法です。

① 10秒要約

1つの節を読み終えたら、次に進む前に10秒だけ手を止め、「結局、何の話だったか」を一言で口に出すかメモします。整った文章である必要はありません。余裕があれば「なぜ必要か」「どこで使うか」を1つ添えます。

⏱️10秒要約タイマー

節を読み終えたら開始し、画面から目を離して要点を一言で述べてください。

10.0

② 手がかりを最小限に使う想起

何も見ずに思い出そうとして出てこないとき、本文全体を読み直すと、再び「見れば分かる」状態に戻ってしまいます。次の手順で、手がかりを最小限にとどめます。

  1. 範囲を狭める：章全体が出てこなければ、1つの節に絞る。
  2. 一部だけ確認する：見出し、キーワード1語、図のいずれかだけを短時間見る。
  3. すぐに閉じて、もう一度自力で答える。

復習カードには、解答の冒頭だけを数秒間表示する「ヒント」機能があります。

③ 就寝前の想起

就寝前に目を閉じ、「今日はどのサービスを学んだか」を軽く思い出します。机も端末も必要ありません。途中で思い出せなくなっても、そこで終えて構いません。

🔬根拠：睡眠と記憶の固定化

学習後の睡眠が記憶の固定化（記憶が安定した状態に移行すること）を助けることは、多くの研究で示されています。就寝前の想起は、その日の学習内容をもう一度取り出す、負担の小さい機会として位置づけてください。

6. 復習のタイミング：間隔反復

エビングハウスの実験以来、学習した内容は学習直後から急速に失われ、その後ゆるやかに減っていくことが知られています（忘却曲線）。また、覚えた直後にその場で何度も繰り返しても、作業記憶の中で言えているだけのことが多く、翌日には抜け落ちます。長く保持するには、想起のタイミングを時間的に分散させることが重要です。

間隔をあけて復習した場合の記憶の推移（概念図）
赤：一度学習しただけの場合。緑：1日後、3日後、7日後…と間隔を広げながら想起した場合。曲線の形は説明用の概念図です。

学習当日から翌日までの3回

タイミング行うこと
学習の直後本文を閉じて、4つの手順で想起する（章末の想起練習）
当日の就寝前その日に学んだサービスを軽く思い出す
翌日の朝・移動中復習カードの「設問一覧」で、設問だけを見て答えを思い出す
🔬根拠：分散学習・間隔反復

同じ総学習時間であれば、一度に集中して行うより、日を分けて複数回に分散したほうが長期的な保持が良いことが、多数の研究で示されています（分散学習効果）。復習の間隔を段階的に広げていく方法を間隔反復と呼びます。

本サイトでは各章の末尾に「学習記録」があり、記録すると1日後 → 3日後 → 7日後 → 14日後 → 30日後の順に次回の復習日を計算します。トップページに当日復習すべき章が表示されるので、それに従って進めてください。

🔬根拠：テスト効果（想起練習）

記憶から情報を取り出す行為そのものが、その記憶を強化します。これをテスト効果、または想起練習（retrieval practice）と呼びます。思い出すのにある程度の努力を要する状態で行うほど効果が高いとされており、これは望ましい困難（desirable difficulties）という考え方で説明されています。

🧠 ここまでの想起練習 （本文を見ずに答えてから開く）
「再認」と「再生（想起）」の違いと、自分がどちらの状態かを確かめる方法は何ですか。
再認は提示された情報を見て分かること、再生は何も見ずに自力で取り出せること。本文を閉じて「何について書かれていたか」を自分で答えられるかで確かめる。
読むときの5つの手順を挙げてください。
予測する → 短く言い換える → 図の上で動かす → 因果関係でつなぐ → 自分の経験に結びつける。
思い出せないときに、本文全体を読み直す代わりに行う3つの手順は何ですか。
範囲を狭める → 見出しやキーワードなど一部だけを短時間確認する → すぐに閉じて、もう一度自力で答える。

7. 記憶を助ける方法

① 全体像から細部へ

個々の知識は、それを位置づける枠組みがないと断片のまま散逸しがちです。各章の冒頭には「この章の全体像」と「読む前の問い」を置いています。先に章の構成を把握し、いま学んでいる内容がどこに位置するかを意識しながら読み進めてください。

② 分類してまとめる（チャンク化）

人が一度に扱える情報の量には限りがありますが、複数の情報を意味のあるまとまりにすると、扱える量が実質的に増えます。これをチャンク化と呼びます。AWS のサービスは200を超えますが、試験範囲のサービスはコンピューティング、ストレージ、データベース、ネットワークといった分野に整理できます。本サイトの章立てもこの分類に従っています。

例：ストレージ分野の3サービスを比較して覚える
S3オブジェクトストレージ
EBSEC2 用のブロックストレージ
EFS複数の EC2 で共有するファイルストレージ
個別に覚えるより、「保存方式の違い」という軸で3つを並べて覚えるほうが、使い分けを問う問題に対応しやすくなります。

③ 言葉と図を結びつける（二重符号化）

情報を言葉だけでなく図やイメージとあわせて記憶すると、想起の手がかりが2系統になり、思い出しやすくなるとされています（二重符号化）。本サイトでは AWS 公式のアイコンを用いた構成図を多く載せています。アイコンの色はサービスの分野を表しているため（オレンジ＝コンピューティング、緑＝ストレージ、紫＝ネットワーク、赤＝セキュリティなど）、色そのものも手がかりになります。

④ サービス名を分解して意味づける

AWS のサービス名の多くは、英単語の組み合わせで機能を表しています。カタカナのまま覚えるより、名前を分解して既に知っている単語の意味と結びつけるほうが、定着しやすく、試験で選択肢を見たときにも機能を推測できます。

サービス名前の分解機能
CloudTrailtrail＝通った跡、足跡誰が・いつ・どの API を呼び出したかの操作履歴を記録する
CloudWatchwatch＝監視するリソースのメトリクスやログを監視し、アラームを発する
CloudFrontfront＝前面、利用者側利用者に近いエッジロケーションからコンテンツを配信する
Elastic Block Storeelastic＝伸縮自在な、block＝ブロック単位、store＝保管容量を変更できるブロックストレージ
Shieldshield＝盾DDoS 攻撃からシステムを保護する

⑤ 頭文字で並びを覚える（頭字法）

決まった項目の並びを覚える必要がある場合は、各項目の頭文字をつなげて覚える方法が有効です。例えば、AWS が優れた設計の基準として定める Well-Architected フレームワークの6つの柱は次のように覚えられます。

🔑覚え方の例

Well-Architected フレームワークの6つの柱：「運・セ・信・パ・コ・サ」
運用上の優秀性／セキュリティ／信頼性／パフォーマンス効率／コスト最適化／持続可能性（サステナビリティ）

各章の「🔑 覚え方」に例を載せていますが、自分で作り直した覚え方のほうが定着しやすいため、必要に応じて置き換えてください。

⑥ 粗く覚えてから、復習で精度を上げる（精緻化）

記憶は、一度で正確に複製されるものではありません。最初は大まかな理解で構わないので先に進み、復習のたびに曖昧な箇所を修正して精度を上げていきます。

  • 一度答えられても、そこで終わりにしない：一度言えただけで復習をやめると、その情報は不要なものとして扱われ、忘れやすくなります。試験まで使い続ける知識として、間隔をあけて繰り返してください。
  • 復習ごとの目標は「前回より楽に、速く、正確に」：例えば CloudWatch と CloudTrail の違いが曖昧であれば、その点を修正します。設問の順序を入れ替えても、迷わず、速く、正確に答えられる状態を目指します。

8. 試験問題で判断を誤らないための6つの視点

AWS 認定試験、特に SAA では、用語の知識だけでなく、条件に対して最も適切な構成を選ぶ判断力が問われます。学習の段階から次の6点を意識すると、初めて見るシナリオ問題にも対応しやすくなります。

陥りやすい誤り改善の方向
① 状況を整理せずに学習法や答えを決める目的・期限・現状を整理してから、優先順位を決める。
② 具体例の暗記で終わる
説明深度の錯覚：説明できるつもりで、実際には説明できない状態		問題を解いたら「要するに何を問う問題か」「別の状況ならどうなるか」を考え、背後にある設計の原則をつかむ。
③ 原因を1つに決めつける模擬試験の得点が伸びない原因を「学習時間不足」だけで片づけず、「想起練習の不足」「比較の観点の整理不足」など、候補を分けて対策する。
④ 曖昧な言葉のまま考える問題文の「高可用性」「運用負荷を最小化」「コスト効率」を、具体的にどのサービスのどの特性を指すのかに言い換える。
⑤ 最初に選んだ答えに固執する
確証バイアス：自分の考えを支持する情報ばかり集める傾向		選択肢を1つ選んだら、「この答えが誤りだとすればどこか」「他の選択肢のほうが条件に合わないか」を検証する。
⑥ 1つの観点だけで判断する「速いから」だけで選ばず、可用性・コスト・性能・運用負荷・セキュリティの複数の観点で比較する。

9. 1日の学習の進め方

タイミング内容目安
① 学習の開始時トップページで当日復習すべき章を確認し、該当する章の想起練習だけを行う（本文は読み返さない。出てこなければ手がかりを最小限に使う）5〜10分
② 復習カード復習期限が来たカードに、「前回より楽に、速く、正確に」を意識して取り組む10分
③ 新しい章全体像と読む前の問いを確認 → 節ごとに10秒要約 → 構成図で流れを確認25〜35分
④ 章を読んだ直後本文を閉じて4つの手順で想起 → 章末の想起練習 → 「学習記録」に記録10分
⑤ 移動中などの空き時間復習カードの「設問一覧」で、設問だけを見て答えを思い出す1〜3分を数回
⑥ 就寝前その日に学んだサービスを軽く思い出す（復習カードの「就寝前の想起」も利用できる）1〜2分

本文中の点線の付いた用語は、タップすると意味が表示されます。用語集ページでは、全章の用語をまとめて検索できます。
