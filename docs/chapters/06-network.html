1. まずは住所の話（IP アドレスと CIDR）

ネットワークの世界では、コンピューター1台1台に住所がついています。これを IP アドレスといいます。

そして「このあたり一帯の住所」をまとめて書く書き方が CIDR（サイダー）です。

🏘️たとえ話：町名と番地

10.0.0.0/16 は「10.0 町まるごと」。10.0.1.0/24 は「10.0 町 1 丁目だけ」。
/ のあとの数字が大きいほど、範囲がせまくなります（/16 は約6万5千個、/24 は256個の住所）。

書き方住所の数よく使う場面
10.0.0.0/1665,536 個VPC 全体（町まるごと）
10.0.1.0/24256 個
うち5個は AWS が予約するので、使えるのは251個		サブネット（1丁目だけ）
📝ことばメモ
IP アドレス
ネットワーク上の住所。パブリック IP＝インターネットから見える住所、プライベート IP＝内側だけで使う住所。
CIDR
住所の範囲の書き方。「/数字」が大きいほどせまい。
ルーティング
データを「どの道を通って届けるか」決めること。

2. VPC ＝ 自分専用のネットワーク

Amazon VPCVirtual Private Cloud／ブイピーシー
AWS の中に作る、自分だけの区切られたネットワーク。ほかの人のシステムとはまじわらない。1つのリージョンの中に作り、その中の AZ にまたがれる。
🏢たとえ話：VPC は「自社ビル」
  • VPC＝ AWS という大きな街に建てた自社ビル。
  • サブネット＝ ビルの中のフロア。1階はお客さんが入れるロビー（パブリック）、上の階は社員だけの事務所（プライベート）。
  • インターネットゲートウェイ＝ ビルの正面玄関。
  • NAT ゲートウェイ＝ 社員が外へ買い物に行くための「出口専用」の通用口。外からは入れない。
  • ルートテーブル＝ 各フロアの案内板（「外へ行くなら玄関へ」）。

EC2 がソフトの更新などで外に出たいときは、NAT ゲートウェイを通って出ます。

パブリックとプライベートは何がちがう？

じつは、サブネットそのものに「公開」というスイッチがあるわけではありません。そのサブネットのルートテーブルに「インターネット行き（0.0.0.0/0）は IGW へ」という道が書いてあるかどうかで決まります。

種類ルートテーブルの中身置くもの
パブリックサブネット0.0.0.0/0 → インターネットゲートウェイロードバランサー、NAT ゲートウェイ、踏み台サーバー
プライベートサブネット0.0.0.0/0 → NAT ゲートウェイ（または外への道なし）アプリのサーバー（EC2）、データベース（RDS）

0.0.0.0/0 は「すべての住所」＝「インターネットのどこでも」という意味です。

インターネットゲートウェイ（IGW）
VPC とインターネットをつなぐ玄関。VPC に1つつける。出入りの両方ができる。
NAT ゲートウェイナット
プライベートサブネットのサーバーが外へ出るだけのための出口。外から中へは入れない。パブリックサブネットに置く。AZ ごとに置くと、AZ が1つ止まっても安心。
NAT＝住所の書きかえ係。
🔑覚え方：「玄関は出入り、NAT は出るだけ」

IGW ＝ 入 ・ 出（パブリック用）／ NAT ＝ 出 だけ（プライベート用）。
「ナット（NAT）くして、出ていくだけ」—— 納得して出ていく社員の姿をイメージ。

3. 2つの門番：セキュリティグループと ネットワーク ACL

VPC には、通っていいデータ・だめなデータを決める門番が2種類います。試験で必ず比べられます。

🚪たとえ話：部屋の鍵と、フロアの警備員
  • セキュリティグループ＝ 部屋（サーバー）ごとの受付係。記憶力がいいので、「さっき中から出かけた人が帰ってきた」ら顔パスで通す。名簿には「入っていい人」だけを書く。
  • ネットワーク ACL＝ フロア（サブネット）の入口の警備員。記憶しないので、行きも帰りもそれぞれチェック。名簿には「入っていい人」も「入ってはだめな人」も書ける。番号の小さいルールから順に見る。
セキュリティグループ（SG）ネットワーク ACL（NACL）
守る単位インスタンス（サーバー）ごとサブネットごと
ルール許可だけ書ける許可と拒否の両方書ける
記憶するかステートフル（帰りは自動で通す）ステートレス（帰りも別に許可が必要）
ルールの見方全部のルールをまとめて判断番号の小さい順に見て、最初に当てはまったもので決定
最初の状態入ってくる通信：すべて拒否／出ていく通信：すべて許可デフォルトの NACL はすべて許可
🔑覚え方：頭文字で「SG は イ・キョ・フル」

SG：インスタンス単位 ／ 許可のみ ／ ステートフル →「いきょうふる（胃きょう古る）」
NACL：その全部が逆（サブネット単位／許可と拒否／ステートレス）。片方だけ覚えれば、もう片方は「逆」で出せます。

🎯試験に出るポイント
  • 「特定の IP アドレスを拒否（ブロック）したい」→ ネットワーク ACL（SG は拒否が書けない）
  • 「Web サーバーには 443番（HTTPS）だけ通したい」→ セキュリティグループ
  • 「DB は Web サーバーからだけ受けつけたい」→ DB の SG に「Web サーバーの SG から」と書く（SG は相手に SG を指定できる）
  • 「プライベートサブネットの EC2 からインターネットへ更新をダウンロード」→ NAT ゲートウェイ

4. VPC どうし・AWS サービスとつなぐ

VPC ピアリングPeering
2つの VPC を1対1で直接つなぐ。別のアカウントや別のリージョンとでも OK。ただし「友だちの友だち」には行けない（A–B、B–C がつながっていても A から C へは行けない）。住所（CIDR）が重なっているとつなげない。
AWS Transit Gatewayトランジットゲートウェイ
たくさんの VPC やオンプレミスを、真ん中の1か所（ハブ）でまとめてつなぐ。空港の「ハブ空港」のイメージ。VPC が多いときはピアリングを何本も張るよりこちら。

VPC エンドポイント
VPC の中から S3 などの AWS サービスへ、インターネットを通らずに行くための専用の通路。2種類ある：
・ゲートウェイ型：S3 と DynamoDB 専用。追加料金なし。
・インターフェース型：多くのサービスに使える。中身は AWS PrivateLink。
AWS PrivateLinkプライベートリンク
AWS のサービスや、ほかの会社の VPC にあるサービスを、自分の VPC 内の住所（プライベート IP）で安全に使えるようにするしくみ。

VPN は一般道（インターネット）の中に、目かくしのトンネルをつくって走るイメージ。すぐ作れるけど、道が混めばおそくなる。

6. お客さんを速く・正しく案内する

Amazon Route 53ルートフィフティースリー
DNS サービス。「www.example.com はどこ？」と聞かれたら住所を答える電話帳。ドメインの購入（登録）や、相手が元気かどうかのヘルスチェックもできる。名前の「53」は DNS が使うポート番号から。
ルーティングポリシー（案内のしかた）かんたんに言うと
シンプル1つの答えを返すだけ
加重（Weighted）「新しい版に1割、古い版に9割」のように割合で振り分け
レイテンシー利用者にとっていちばん速いリージョンへ
フェイルオーバー本番がこわれたら予備へ切りかえ（ヘルスチェックと組み合わせる）
位置情報（Geolocation）利用者がいる国・地域で振り分け（「日本の人には日本語サイト」）
地理的近接性・複数値回答・IP ベース距離で振り分け／複数の答えを返す／利用者の IP の範囲で振り分け
Amazon CloudFrontクラウドフロント
CDN。世界中のエッジロケーションに画像・動画・Web ページをキャッシュして、近くから速く届ける。S3 や ALB を元データ（オリジン）にする。たとえるなら全国のコンビニ。DDoS 対策の Shield Standard が自動でつき、WAF も組み合わせられる。
AWS Global Acceleratorグローバルアクセラレーター
利用者を近くのエッジからAWS 専用の高速道路（バックボーン）にのせて、アプリまで速く届ける。固定の IP アドレスが2つもらえる。キャッシュはしない。ゲームなど TCP/UDP の通信や、すばやい切りかえが必要なときに使う。

ロードバランサー（ELB：ALB・NLB など）は、サーバーに仕事を振り分ける係です。くわしくは 第3章 コンピューティング を見てください。

⚠️ひっかけ注意
  • CloudFront と Global Accelerator：どちらもエッジを使うが、キャッシュする（CloudFront）／しない（Global Accelerator）。「固定 IP が欲しい」「HTTP 以外」→ Global Accelerator。
  • NAT ゲートウェイはパブリックサブネットに置く（使うのはプライベートのサーバーだけど、置き場所はパブリック）。
  • VPC ピアリングは「友だちの友だち」に行けない（推移的なルーティングはできない）。
  • SG では拒否が書けない。「拒否」と出たら NACL を思い出す。

10.0.0.0/16 と 10.0.1.0/24、範囲が広いのはどっち？
/16 のほう（約6万5千個）。/ のあとの数字が大きいほどせまい（/24 は256個）。
VPC を自社ビルにたとえると、サブネット・IGW・NAT ゲートウェイ・ルートテーブルはそれぞれ何？
サブネット＝フロア、IGW＝正面玄関（出入り両方）、NAT ゲートウェイ＝出口専用の通用口、ルートテーブル＝案内板。
サブネットが「パブリック」になる条件は？
ルートテーブルに「0.0.0.0/0 → インターネットゲートウェイ」の道があること。
プライベートサブネットの EC2 が、外からは入られずに外へ出るには？ それはどこに置く？
NAT ゲートウェイを使う。NAT ゲートウェイはパブリックサブネットに置く。
セキュリティグループとネットワーク ACL のちがいを3つ。
SG＝インスタンス単位・許可のみ・ステートフル。NACL＝サブネット単位・許可と拒否・ステートレス。
特定の IP アドレスからの通信をブロックしたい。使うのは？
ネットワーク ACL（拒否ルールが書ける）。
たくさんの VPC とオンプレミスをまとめてつなぐサービスは？
AWS Transit Gateway（ハブとしてまとめる）。
S3 へインターネットを通らずに行く、追加料金なしの方法は？
ゲートウェイ型の VPC エンドポイント（S3 と DynamoDB 用）。
Site-to-Site VPN と Direct Connect のちがいは？
VPN＝インターネット上の暗号化トンネル。すぐ使えるが安定性はふつう。Direct Connect＝専用線。速く安定だが準備に時間がかかる。
CloudFront と Global Accelerator のちがいは？
CloudFront はエッジでキャッシュして配信する CDN。Global Accelerator はキャッシュせず、固定 IP と AWS の高速網で TCP/UDP 通信を速くする。
Route 53 で「本番がダウンしたら予備サイトへ」を実現するルーティングは？
フェイルオーバールーティング（ヘルスチェックと組み合わせる）。
