1. 連携 —— 疎結合とメッセージングのサービス

システムは複数のコンポーネント（サーバーやプログラム）で構成されます。コンポーネント同士が直接呼び出し合い、互いの状態に強く依存している状態を密結合、間にキューなどの仲介役を置き、依存を弱めた状態を疎結合といいます。AWS は、障害に強くスケールしやすい設計として疎結合を推奨しています。

💡イメージで理解する

飲食店の注文処理に置き換えると分かりやすくなります。密結合は、注文を受けた担当者が調理担当に直接手渡しし、受け取られるまで待つ運用です。調理側が混雑すると、受付も止まります。

疎結合は、受付担当が注文票を所定の棚（キュー）に置いてすぐ次の受付に戻る運用です。調理担当は自分の処理能力に合わせて棚から取り出します。調理担当が一時的に不在でも、注文票は失われません。

📝用語の補足
メッセージ
コンポーネント間で受け渡すデータの単位。注文内容や処理依頼など。
キュー
メッセージを到着順に一時保管する領域。英語の queue（待ち行列）に由来。
プッシュ
送信側から受信側へ能動的に配信する方式。SNS が該当。
ポーリング
受信側が定期的に問い合わせてデータを取得する方式。SQS が該当。
サーバーレス
利用者がサーバーの構築・運用を行わずに済むサービス形態。基盤の管理は AWS が担う。
Amazon SQSSimple Queue Service
メッセージを一時的に保持するフルマネージドのキュー。受信側がポーリングで取得する。疎結合化の代表的な手段。1つのメッセージは原則として1つの受信側が処理する。
Amazon SNSSimple Notification Service
1つの通知を複数の宛先へ同時に配信する（プッシュ型）。メール・SMS・SQS・Lambda などに送信できる。Pub/Sub 型のメッセージング。
Amazon EventBridgeイベントブリッジ
AWS サービスや外部 SaaS で発生したイベントをルールに基づいて振り分けるイベントバス。「毎日9時に実行」といったスケジュール実行にも対応する。
AWS Step Functionsステップ ファンクションズ
複数の処理を定義した順序で実行し、失敗時の再試行や分岐を制御するオーケストレーションサービス。処理の流れ（ワークフロー）を視覚的に設計できる。
Amazon API GatewayAPI ゲートウェイ
外部からのリクエストを受け付けるAPI の窓口を作成・公開・管理する。認証やアクセス制限も担う。API Gateway ＋ Lambda はサーバーレス構成の定番。
サービス役割配信方式要点
SQSメッセージを保持するポーリング（受信側が取得）疎結合・バッファリング
SNS複数の宛先へ同時配信プッシュPub/Sub・ファンアウト
EventBridgeイベントを振り分けるルールに基づく配信イベント駆動・定期実行
Step Functions処理順序を制御するワークフロー管理再試行・分岐
API Gateway外部リクエストの受付リクエスト/レスポンスAPI の公開・管理
🔑覚え方：名前の中央の1文字で区別する

SQS の Q は Queue（待ち行列）＝ 保持する。SNS の N は Notification（通知）＝ 一斉に知らせる。

🎯試験での問われ方
  • 「コンポーネントを疎結合にしたい」「処理が追いつかないときにリクエストを保持したい」→ SQS
  • 「1つの通知を複数の宛先（メール・SMS など）に送りたい」→ SNS
  • 「AWS で発生したイベントをきっかけに処理したい」「定期実行したい」→ EventBridge
  • 「複数の Lambda を順番に実行し、エラー時は再試行したい」→ Step Functions

📝用語の補足
ストリーミングデータ
継続的に発生し続けるデータ。クリック履歴、センサー値、ログなど。
ETL
Extract（抽出）・Transform（変換）・Load（格納）。データを分析しやすい形に加工して格納する処理。
データレイク
形式を問わず、データを元の形のまま大量に保管する場所。AWS では S3 が中心となる。
DWH（データウェアハウス）
分析用に整理・構造化したデータを蓄積するデータベース。Redshift が該当。
SQL
データベースに対して検索・集計などを指示するための言語。
BI
Business Intelligence。データをグラフやダッシュボード（指標を一覧表示する画面）で可視化し、意思決定に活用すること。
ビッグデータ
一般的なコンピューター1台では処理しきれない規模のデータ。
Amazon Kinesisキネシス
リアルタイムに発生するデータを収集・処理する。Kinesis Data Streams（ストリームの受け取り）、Amazon Data Firehose（旧 Kinesis Data Firehose。S3 や Redshift などへ自動配信）、Kinesis Video Streams（動画）がある。
AWS Glueグルー
サーバーレスの ETL サービス。どこにどのようなデータがあるかを管理するデータカタログ（データの目録）も提供する。
Amazon Athenaアテナ
S3 上のデータに対して、直接 SQL でクエリを実行できる。サーバーレスで、スキャンしたデータ量に応じて課金される。
Amazon EMRイーエムアール
ビッグデータを多数のサーバーで分散処理する。Hadoop や Spark の環境を容易に構築できる。
Amazon Redshiftレッドシフト
分析用のデータウェアハウス。大量データの集計に強い。詳しくは第5章 データベースを参照。
Amazon Quick Sightクイックサイト（旧 Amazon QuickSight）
データをグラフやダッシュボードで可視化する BI サービス。2025年10月に AI 機能などと統合され Amazon Quick Suite（その後「Amazon Quick」に改称）という製品群になり、BI 機能は「Quick Sight」と呼ばれています。試験では「Amazon QuickSight」と表記されることが多いため、両方の名称を押さえておきましょう。
Amazon OpenSearch Serviceオープンサーチ
大量のログや文書を高速に検索・分析する。サイト内検索やログ分析に用いる（旧 Elasticsearch Service）。
AWS Lake Formationレイク フォーメーション
データレイクを短期間で構築し、誰がどのデータにアクセスできるか（権限）を一元管理する。
🔑覚え方：名前の由来で結びつける

Athena はギリシャ神話の知恵の女神。データレイク（S3）に対して問い（SQL）を投げると答えが返るサービスと結びつけます。
Kinesis はギリシャ語で「運動」。流れ続けるデータ（ストリーミング）を扱うサービスです。

⚠️間違えやすい点
  • Athena（S3 に直接 SQL・サーバーレス）と Redshift（データをロードして大規模に集計する DWH）を混同しないこと。「S3 のデータをそのまま」「アドホック（その場限り）な分析」であれば Athena です。
  • 「リアルタイム」「ストリーミング」とあれば Kinesis。Glue はバッチ処理（まとめて処理）向けです。
  • 可視化（BI）は QuickSight / Quick Sight。CloudWatch のダッシュボード（監視用）とは目的が異なります。

3. AI・機械学習のサービス

AI 関連のサービスは、3つの層に分けて整理します。上の層ほどすぐに利用でき、下の層ほど自由度が高く独自に構築できます。

💡イメージで理解する
  • 上の層（学習済み AI サービス）：画像認識や音声の文字起こしなど、特定の用途向けに学習済みの機能を API で呼び出すだけで使える。機械学習の専門知識は不要。
  • 中間の層（生成 AI）：Bedrock で各社の基盤モデルを選び、自社の用途に合わせてアプリケーションを構築する。
  • 下の層（機械学習基盤）：SageMaker AI で、自社のデータから独自のモデルを構築・学習・運用する。
📝用語の補足
機械学習（ML）
大量のデータからパターンや規則をコンピューターに学習させる技術。
モデル
機械学習によって作られた判断・予測の仕組み。データを入力すると予測結果を出力する。
生成 AI
文章・画像・プログラムなどを新たに生成する AI。
基盤モデル（FM）
大量のデータで事前学習された、幅広い用途に使える大規模な AI モデル。生成 AI の土台となる。
自然言語処理（NLP）
人間が日常的に使う言語（自然言語）をコンピューターで解析・処理する技術。
OCR
画像内の文字を認識し、テキストデータに変換する技術。

下の層・中間の層：独自に構築する／生成 AI

Amazon SageMaker AIセージメーカー
機械学習モデルの構築・学習・デプロイまでを一貫して行える、開発者・データサイエンティスト向けのプラットフォーム。（2024年末に「SageMaker AI」へ改称され、「SageMaker」はデータ分析も含む上位ブランド名になりました）
Amazon Bedrockベッドロック
複数の企業の基盤モデル（Anthropic の Claude、Amazon Nova など）を API 経由で利用できるフルマネージドの生成 AI サービス。インフラ管理は不要。Bedrock は英語で「岩盤（基盤）」の意。
Amazon Qアマゾン キュー
業務を支援する生成 AI アシスタント。開発者向けの Amazon Q Developer（コード生成や AWS に関する質問への回答）と、社内データに基づいて回答する Amazon Q Business がある。

🎯試験での問われ方
  • 「機械学習の専門知識なしで」画像認識・翻訳などを利用したい → 上の層（Rekognition・Translate など）
  • 「独自の ML モデルを構築・トレーニング・デプロイしたい」→ SageMaker（AI）
  • 「基盤モデルを使って生成 AI アプリケーションを構築したい」「インフラ管理なしで」→ Bedrock
  • 「コールセンターの通話を文字起こしし、顧客の感情を分析したい」→ Transcribe ＋ Comprehend
⚠️間違えやすい点

Polly と Transcribe は変換の方向が逆です。Polly は「テキスト→音声」、Transcribe は「音声→テキスト」。
Textract と Comprehend も混同しやすい組み合わせです。Textract は画像から文字を抽出するだけで、文章の意味を解析するのは Comprehend です。

移行戦略「7つの R」

R意味具体例
Rehost（リホスト）変更せずにそのまま移す。リフト＆シフトとも呼ぶオンプレミスのサーバーを EC2 へ複製する
Replatform（リプラットフォーム）一部を最適化して移す自前のデータベースを RDS に置き換える
Refactor（リファクタリング）クラウド向けに設計し直すサーバーレスやマイクロサービスに作り替える
Repurchase（リパーチェス）別の製品（SaaS など）に切り替える自社運用の CRM を SaaS 製品に置き換える
Retire（リタイア）不要なシステムを廃止する利用者のいないアプリケーションを停止する
Retain（リテイン）当面は移行せず残す制約のあるシステムをオンプレミスで維持する
Relocate（リロケート）VMware 環境などをそのままの形でクラウドへ移すVMware Cloud on AWS へ移す

※以前は Relocate を除いた「6つの R」でしたが、現在は「7つの R」が基本です。

🧠 想起練習

本文を見ずに答えを思い出してから、各項目を開いて確認してください。

疎結合とは何か。また、それを実現する代表的なサービスは？
コンポーネント間の依存を弱め、一方が停止・遅延しても他方が影響を受けにくくする設計。間にキュー（SQS）を置いてメッセージを保持させるのが代表的な方法。
SQS と SNS の違いは？
SQS はメッセージを保持するキューで、受信側がポーリングで取得する。SNS は1つの通知を複数の宛先へ同時に配信する（プッシュ型、Pub/Sub）。
「複数の処理を順番に実行し、失敗したら再試行する」流れを構築するサービスは？
AWS Step Functions。
データ分析の5つの工程と、それぞれの代表的なサービスは？
収集（Kinesis）→ 加工（Glue）→ 蓄積（S3 / Redshift）→ 分析（Athena / EMR）→ 可視化（QuickSight ＝ 現在の Quick Sight）。
S3 上のデータに、サーバーを用意せず直接 SQL を実行できるサービスは？
Amazon Athena（スキャンしたデータ量に応じて課金）。
SageMaker と Bedrock の違いは？
SageMaker（AI）は独自の ML モデルを構築・学習・デプロイするためのプラットフォーム。Bedrock は既存の基盤モデルを API 経由で利用できる生成 AI サービス。
画像・動画の解析、音声の文字起こし、テキストの読み上げ、文章の感情分析を担うサービスはそれぞれ？
画像・動画＝Rekognition、音声→テキスト＝Transcribe、テキスト→音声＝Polly、感情分析＝Comprehend。
書類の画像から文字や表を抽出するサービスは？
Amazon Textract。
サーバーをそのまま AWS に移す（リホスト）ときのサービスは？ データベースを移すときは？
サーバーは AWS Application Migration Service（MGN）、データベースは AWS DMS。全体の進捗は Migration Hub で管理する。
移行戦略「7つの R」をすべて挙げてください。
Rehost（そのまま移す）、Replatform（一部最適化）、Refactor（設計し直す）、Repurchase（別製品に切り替える）、Retire（廃止する）、Retain（残す）、Relocate（環境ごと移す）。
