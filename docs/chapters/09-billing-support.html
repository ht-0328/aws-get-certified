第9章 料金とサポート

CLF では請求・料金・サポートが出題の約12%を占めます。料金は稼働時間・容量・外へ出るデータ量で決まります。見積もりは Pricing Calculator、予算の通知は Budgets です。サポートは上位プランほど応答が速く手厚くなります。暗記で確実に得点できる分野です。

🧭この章で理解してほしいこと
  • 料金は稼働時間・容量・外へ出るデータ量：入るデータは無料、出るデータは有料
    • コンピューティング：サーバーの稼働時間（秒・時間単位）
    • ストレージ：保存したデータの容量（GB×月）
    • データ転送：AWS から外部へ送信した量
      • インバウンド（外から AWS へ）は原則無料
      • アウトバウンド（AWS から外へ）は有料。量が多いほど単価は下がる
      • AZ をまたぐ通信やリージョン間の通信にも料金がかかることがある
    • TCO：購入費だけでなく電力・設置場所・人件費まで含めた総コスト
    • 「アップロードは有料か」と問われたら、原則無料が正解
  • 無料利用枠は2025年7月15日を境に制度が違う：以降はクレジット制、以前は12か月無料
    • 新制度：クレジット（登録時100ドル＋試用で最大100ドル追加）
      • 無料プラン：最大6か月か、クレジットを使い切るまで。一部は不可
      • 有料プラン：全サービス。クレジットを超えた分を請求
    • 旧制度：サービスごとの12か月無料枠（小規模な EC2 を月750時間など）
    • 常時無料（Lambda 月100万リクエストなど）はどちらでも使える
    • 試験では「常時無料・期間限定・トライアルの3種類」の区分で出ることも
  • 割引は引き受ける制約が大きいほど大きい：約束なし → 定価、長期 → 72%、中断可 → 90%
    • オンデマンド：使った分だけ払う。縛りなし。定価
    • Savings Plans：1時間あたりの利用額を1年か3年使うと約束。最大約72%引き
      • インスタンスの種類を後から変えられる
    • リザーブドインスタンス：構成を固定して1年か3年予約。最大約72%引き
    • スポット：余剰を最大約90%引き。AWS の都合で中断される
    • Dedicated Hosts：物理サーバーの専有。割高。ライセンス持ち込みや規制向け
    • Organizations の一括請求：複数アカウントの請求を1つにまとめる
      • 使用量が合算され、ボリューム割引を受けやすい
      • RI・Savings Plans の割引をアカウント間で共有できる
      • 追加料金はかからない
      • 「部門ごとの支払いをまとめたい」→ Organizations（CUR はレポートだけ）
  • コストの道具は見積もる・把握する・管理する：通知が要るなら Budgets
    • 見積もる：Pricing Calculator。構築前の月額を見積もる。無料・ログイン不要
    • 把握する
      • Billing and Cost Management コンソール：請求額・請求書・支払い方法
      • Cost Explorer：コストをグラフで分析し、将来を予測する。通知はしない
      • Cost and Usage Report（CUR）：最も詳細なデータを S3 に出力する
    • 管理する
      • Budgets：予算を設定し、超えそうなとき・超えたときに通知する
      • Cost Anomaly Detection：急なコスト増を機械学習で検知して通知する
    • コスト配分タグ：「部署=営業部」のタグで部署別・プロジェクト別に集計
    • 予算管理の通知は Budgets が標準の答え（CloudWatch の請求アラームではなく）
    • Calculator＝計算機、Explorer＝探索して分析、Budgets＝予算
  • サポートは上位ほど応答が速く手厚い：12時間 → 1時間 → 30分 → 15分
    • ベーシック：無料。技術サポートなし（請求・アカウントの問い合わせのみ）
    • デベロッパー：営業時間内のメール。障害は12営業時間以内
    • ビジネス：24時間365日の電話・チャット。本番停止は1時間以内
      • Trusted Advisor の全チェックが使える
      • 「最も低コストで本番向けに24時間の電話サポート」の答え
    • エンタープライズ On-Ramp：30分以内。TAM のチーム（プール）が支援
    • エンタープライズ：15分以内。専任の TAM とコンシェルジュ（請求の窓口）
    • 専任 TAM はエンタープライズだけ、24時間の電話はビジネス以上
    • 「電話のテクニカルサポートがある最下位」→ ビジネス（デベロッパーはメール）
    • 2025年12月に「Basic ＋ 3つの有料プラン」に再編された
      • Business Support+（30分）、Enterprise Support（15分）
      • Unified Operations（5分。最重要システム向け）
      • 試験は旧プラン名で出る可能性が高い。旧プランは2027年1月1日まで
  • 点検は Trusted Advisor、障害は Health Dashboard：困ったときの窓口は目的で選ぶ
    • Trusted Advisor：環境を自動で点検し、改善点を出す
      • 分野はコスト・パフォーマンス・セキュリティ・耐障害性・クォータ・運用の6つ
      • 全チェックはビジネス以上。「未使用リソースを見つけてコスト削減」の答え
      • 「全開放のセキュリティグループを見つけたい」も Trusted Advisor
    • Health Dashboard：AWS 側の障害やメンテナンスの情報。無料
    • re:Post：無料の Q&A コミュニティ。AWS の専門家が答えることも
    • Marketplace：サードパーティ製ソフトを買えるカタログ。AWS の請求に統合
    • Partner Network（APN）：構築を支援するパートナー企業
    • Professional Services：AWS 社員の専門家チームによる有料の支援
    • AWS IQ：外部の専門家に依頼するサービスだったが、2026年5月28日に終了
    • Skill Builder・公式ドキュメント・ナレッジセンター：自己解決の第一の情報源

読み終えたら、本文を見ずに各項目を自分の言葉で説明できるか確かめてください。

1. 料金を決める3つの要素

AWS の料金は、ほぼすべて次の3つの要素で決まります。

② ストレージ保存したデータの容量
（GB × 月）
③ データ転送AWS から外部へ送信した

インターネット（利用者）

←送信（アウト）＝ 有料
AWS
AWS に入ってくるデータ（インバウンド）は原則無料、AWS から出ていくデータ（アウトバウンド）は有料です。
📝用語の補足
インバウンド
外部から AWS へ入ってくる通信。原則無料。
アウトバウンド
AWS から外部へ出ていく通信。有料（転送量が多いほど 1GB あたりの単価は下がる）。
従量課金
使用量に応じて料金を支払う方式。AWS の基本的な料金体系。
TCO
Total Cost of Ownership（総保有コスト）。機器の購入費だけでなく、電力・設置場所・運用人件費まで含めた総コスト。オンプレミスとクラウドの比較に用いる。
⚠️間違えやすい点

「AWS へのデータのアップロード（インバウンド）は有料か」という問いに対しては、原則無料が正解です。一方、同一リージョン内でもAZ をまたぐ通信や、リージョン間の通信には料金が発生する場合があります。

2. 無料利用枠（Free Tier）

AWS には、一定の範囲内で無料で利用できる無料利用枠があります。2025年7月15日以降に作成するアカウントから、制度が変更されました。

2025年7月15日以降に作成したアカウント（現行制度）それ以前のアカウント（旧制度）
中心となる仕組みクレジット（AWS の利用料金に充当できる残高）。登録時に 100ドル分、さらに EC2・Lambda・Bedrock・Budgets などを試用すると最大100ドル分が追加（合計最大200ドル）サービスごとの「12か月無料」枠（例：小規模な EC2 を月750時間まで）
プランの選択無料プラン：最大6か月、またはクレジットを使い切るまで。課金は発生しないが一部サービスは利用不可
有料プラン：全サービスを利用でき、クレジットを超えた分が請求される		選択なし（12か月経過後は自動的に通常料金）
常時無料常時無料のサービス（例：Lambda の月100万リクエスト、DynamoDB の一定量など）は、どちらの制度でも利用できる

※詳細な条件は変更される可能性があるため、利用前に AWS 公式の「AWS 無料利用枠」ページを確認してください。試験では「無料利用枠には、常時無料・期間限定（12か月など）・トライアルの3種類がある」という従来の区分で出題される場合もあります。

3. 割引の仕組み

購入オプションの整理（詳しくは第3章）

購入方法仕組み割引率適した用途
オンデマンド使用した分だけ支払う。契約期間の縛りなしなし（定価）短期間・需要が予測できない・検証用途
Savings Plans「1時間あたり〇ドル分を利用する」と1年または3年コミット最大約72%継続的に利用し、インスタンスの種類を後から変更したい
リザーブドインスタンス（RI）特定のインスタンス構成を1年または3年予約最大約72%同じ構成で継続的に利用する
スポットインスタンスAWS の余剰キャパシティを割安に利用。AWS 側の都合で中断される場合がある最大約90%中断されても問題ない処理（バッチ・分析など）
Dedicated Hosts物理サーバーを専有するなし（割高）既存ソフトウェアのライセンスを持ち込みたい、規制上専有が必要
🔑覚え方：割引率は「利用者が引き受ける制約」の大きさに比例する

制約なし（オンデマンド）＝ 定価。1〜3年の利用をコミット（Savings Plans / RI）＝ 最大約72%引き。いつ中断されても受け入れる（スポット）＝ 最大約90%引き。

一括請求（AWS Organizations）

企業で複数の AWS アカウントを利用している場合、AWS Organizations の一括請求（Consolidated Billing）を使うと、次のメリットがあります。

  • 請求が1つにまとまる（支払いは管理アカウントが一括で行う）
  • 全アカウントの使用量が合算されるため、ボリューム割引（使用量が多いほど単価が下がる）を受けやすい
  • リザーブドインスタンスや Savings Plans の割引をアカウント間で共有できる
  • 一括請求の機能自体に追加料金はかからない

4. コストを「見積もる・把握する・管理する」ツール

料金関連のツールは、利用のどの段階で使うかによって3つに分類すると整理しやすくなります。

段階サービス機能
利用前（見積もる）AWS Pricing Calculatorこれから構築する構成の月額料金を見積もる（無料・ログイン不要）
利用後（把握する）Billing and Cost Management コンソール当月の請求額や請求書の確認、支払い方法の設定を行う画面
AWS Cost Explorerコストをグラフで分析する。サービス別・月別の表示に加え、過去の傾向から将来のコストを予測できる。RI や Savings Plans の推奨も表示される
AWS Cost and Usage Report（CUR）最も詳細な使用量・料金データを S3 にファイル出力する。独自の詳細分析向け（現在は「データエクスポート」機能内の CUR 2.0）
超過防止（管理する）AWS Budgets予算を設定し、超過しそうなとき・超過したときにメールなどで通知する。対応アクションの自動実行も可能
AWS Cost Anomaly Detection機械学習により通常と異なる急激なコスト増加を検知して通知する

コスト配分タグ

AWS のリソースにはタグを付与できます。「部署=営業部」「プロジェクト=新サイト」のようなタグをコスト配分タグとして有効化すると、部署別・プロジェクト別にコストを分けて集計できます（Cost Explorer などで利用可能）。

🔑覚え方：サービス名の英語の意味で対応づける

見積もる＝Pricing Calculator（計算機）／ 把握する＝Cost Explorer（探索して分析する）／ 管理する＝Budgets（予算）

🎯試験での問われ方
  • 「AWS に移行した場合の費用を見積もりたい」→ Pricing Calculator
  • 「過去のコストの傾向をグラフで確認したい」「将来のコストを予測したい」→ Cost Explorer
  • 「予算を超えたらアラートを出したい」→ Budgets
  • 「最も詳細な請求データが欲しい」→ Cost and Usage Report
  • 「部署ごとにコストを分けたい」→ コスト配分タグ
  • 「複数アカウントの請求をまとめ、ボリューム割引を受けたい」→ Organizations の一括請求
  • 「部門ごとのアカウントの支払いをまとめ、統制（ガバナンス）も1か所に」→ Organizations で組織を作り、全アカウントを招待する（Cost and Usage Report はレポートを出すだけ）
⚠️間違えやすい点

Budgets と CloudWatch の請求アラームは、どちらも「料金が〇ドルを超えたら通知」を実現できますが、予算管理が目的なら Budgets が標準的な解答です。
また、Cost Explorer は分析・可視化のツールであり通知機能は持ちません。通知まで行うのは Budgets です。

5. サポートプラン

AWS の技術者に問い合わせるためには、サポートプランの契約が必要です。プランによって応答時間や受けられる支援が異なります。

⚠️2025年12月にプラン体系が刷新されました

AWS は2025年12月に、サポートプランを「Basic（無料）＋ 3つの有料プラン」へ再編すると発表しました。ただし、CLF-C02 試験では旧プラン名で出題される可能性が高いため、ここでは両方を説明します。旧プラン（Developer・Business・Enterprise On-Ramp）は 2027年1月1日まで利用できる予定です。

  • 「無制限アクセスを許可しているセキュリティグループを特定したい」→ Trusted Advisor

6. その他の支援

AWS Marketplaceマーケットプレイス
サードパーティ製のソフトウェアやサービスを検索・購入できるデジタルカタログ。料金は AWS の請求に統合される。
AWS Partner Network（APN）パートナー ネットワーク
AWS を活用したシステム構築を支援するパートナー企業のネットワーク。コンサルティング企業やソフトウェア企業が参加している。
AWS re:Postリポスト

🧠 想起練習

本文を見ずに答えを思い出してから、各項目を開いて確認してください。

AWS の料金を決める3つの要素は？ データ転送はどちらの方向が有料？
コンピューティング（稼働時間）、ストレージ（容量）、データ転送。AWS から外部への送信（アウトバウンド）が有料で、受信（インバウンド）は原則無料。
2025年7月15日以降に作成したアカウントの無料利用枠の仕組みは？
クレジット制（登録時100ドル＋試用で最大100ドル追加）。無料プラン（最大6か月またはクレジットを使い切るまで）と有料プランを選択する。常時無料のサービスはどちらでも利用できる。
購入オプションを割引率の大きい順に並べると？
スポット（最大約90%、中断あり）→ Savings Plans / リザーブドインスタンス（1年または3年のコミットで最大約72%）→ オンデマンド（定価）。
Organizations の一括請求のメリットは？
請求が1つにまとまる、使用量の合算でボリューム割引を受けやすい、RI / Savings Plans の割引をアカウント間で共有できる、追加料金がかからない。
「見積もる・把握する・管理する」それぞれに対応するツールは？
見積もる＝Pricing Calculator、把握する＝Cost Explorer（グラフ・予測）／CUR（最も詳細なデータ）／Billing コンソール、管理する＝Budgets（予算アラート）／Cost Anomaly Detection（異常検知）。
部署ごとにコストを分けて集計したい場合の方法は？
コスト配分タグを有効化して集計する。
従来の5つのサポートプランと、それぞれの最短応答時間は？
ベーシック（技術サポートなし）、デベロッパー（12営業時間）、ビジネス（1時間）、エンタープライズ On-Ramp（30分）、エンタープライズ（15分）。
専任の TAM が付くプランは？ 24時間の電話サポートはどのプランから？
専任 TAM はエンタープライズ（On-Ramp は TAM のチーム）。24時間の電話・チャットはビジネス以上。
Trusted Advisor が点検する6分野は？ すべてのチェックを使えるのはどのプランから？
コスト最適化・パフォーマンス・セキュリティ・耐障害性・サービスクォータ・運用上の優秀性。すべてのチェックはビジネス以上。
re:Post・Marketplace・Professional Services の違いは？
re:Post＝無料の Q&A コミュニティ、Marketplace＝サードパーティ製ソフトウェアを購入できるカタログ、Professional Services＝AWS 社員の専門家チームによる有料支援。
