第9章 料金とサポート

クラウドプラクティショナー（CLF）試験では、「お金」と「困ったときの助け」の分野が全体の約12%を占めます。覚えれば確実に点になる、コスパのいい章です。

🗺️この章の地図

  2. 無料利用枠（2025年に大きく変わった）

1. 料金の3つの基本

AWS の料金は、ほぼすべて次の3つで決まります。

AWS で お金がかかる3つのもの
① コンピューティングサーバーを動かした時間
（秒・時間単位）
② ストレージ保存したデータの量
（GB × 月）
③ データ転送AWS から外へ出す
データの量
データ転送のルール
インターネット
→入れる（イン）＝ 無料
←出す（アウト）＝ 有料
AWS
AWS に入ってくるデータ（インバウンド）は基本無料、AWS から出ていくデータ（アウトバウンド）は有料。
🏨たとえ話：ホテルの料金

① 部屋に泊まった日数（コンピューティング）、② 預けた荷物の量（ストレージ）、③ 荷物を外に送り出す宅配便代（データ転送のアウト）。
荷物を持ち込むのはタダ、でも送り出すと送料がかかる。お客さんに来てほしいホテルらしいルールです。

📝ことばメモ
インバウンド
外から入ってくる通信。AWS では基本無料。
アウトバウンド
中から出ていく通信。AWS では有料（量が多いほど1GBあたりは安くなる）。
従量課金
使った分だけ払うしくみ。AWS の基本。
TCO
Total Cost of Ownership（総保有コスト）。機械代だけでなく、電気・場所・人件費まで全部ふくめた本当のコスト。オンプレとクラウドを比べるときに使う。
⚠️ひっかけ注意

「AWS へのデータのアップロード（インバウンド）は有料？」→ 基本無料です。また、同じリージョンの中でも AZ をまたぐ通信や、リージョン間の通信には料金がかかることがあります。

2. 無料利用枠（フリーティア）

AWS には、はじめての人が試せる無料利用枠があります。2025年7月15日から、新しく作るアカウントのしくみが変わりました。

2025年7月15日以降に作ったアカウント（今のしくみ）それより前のアカウント（昔のしくみ）
中心となるものクレジット（AWS で使える「ポイント」）。登録時に 100ドル分、さらに EC2・Lambda・Bedrock・Budgets などを試すと最大100ドル分追加（合計で最大200ドル）サービスごとの「12か月無料」枠（例：小さい EC2 を月750時間まで）
プランの選択無料プラン：最大6か月 または クレジットを使い切るまで。お金はかからないが一部サービスは使えない
有料プラン：全サービスが使え、クレジット分を超えたら請求		選択なし（12か月をすぎると自動で通常料金）
ずっと無料常に無料のサービス（例：Lambda の月100万リクエスト、DynamoDB の一定量など）は、どちらでも使える

※細かい条件は変わることがあるので、使う前に AWS 公式の「AWS 無料利用枠」ページで確認してください。試験では「無料利用枠には、常に無料・期間限定（12か月など）・トライアルの種類がある」という昔からの分け方で出ることもあります。

3. 割引のしくみ

購入オプションのおさらい（くわしくは第3章）

買い方しくみ割引向いている使い方
オンデマンド使った分だけ。約束なしなし（定価）短期間・予測できない・お試し
Savings Plans「1時間あたり〇ドル分使います」を1年か3年約束最大約72%ずっと使う。インスタンスの種類をあとから変えたい
リザーブドインスタンス（RI）特定のインスタンスを1年か3年予約最大約72%ずっと同じ構成で使う
スポットインスタンスAWS の空き容量を安く使う。AWS の都合で中断されることあり最大約90%止まってもいい処理（バッチ・分析など）
Dedicated Hosts物理サーバーをまるごと専用になし（高い）今あるソフトのライセンスを持ち込みたい、規則で専用が必要
🔑覚え方：割引は「約束の強さ」に比例する

何も約束しない（オンデマンド）＝ 定価。1〜3年使うと約束（Savings Plans / RI）＝ 約7割引。いつ追い出されても文句を言わない（スポット）＝ 約9割引。
「長く・ゆるく約束 → 安い、追い出しOK → もっと安い」と覚えます。

一括請求（AWS Organizations）

会社でたくさんの AWS アカウントを使っているとき、AWS Organizations の一括請求（コンソリデーティッドビリング）を使うと：

  • 請求書が1枚にまとまる（支払いは管理アカウントがまとめて行う）
  • 全アカウントの使用量を合計して計算されるので、ボリューム割引（たくさん使うほど安くなる）を受けやすい
  • リザーブドインスタンスや Savings Plans の割引をアカウント間で分け合える
  • 一括請求そのものに追加料金はかからない
一括請求のイメージ
開発用アカウント
本番用アカウント
分析用アカウント
→使用量を合計
管理アカウント請求書は1枚
ボリューム割引
家族のスマホ代を「家族まとめて割」で1つの請求にするのと同じ発想です。

4. お金を「見積もる・見る・守る」ツール

料金ツールは時間の流れで3つのグループに分けると覚えやすくなります。

👛たとえ話：おこづかいの管理
  • 使う前に「いくらかかるかな？」と計算する＝ 見積もり → Pricing Calculator
  • 使ったあとに家計簿で「何に使った？」をふり返る＝ 見える化 → Cost Explorer・CUR・Billing コンソール
  • 使いすぎないように「今月は3,000円まで！」と決めて見張る＝ 守る → Budgets・Cost Anomaly Detection
いつサービス何をする？
使う前AWS Pricing Calculatorこれから作る構成の月額料金を見積もる（無料・ログイン不要）
使ったあとBilling and Cost Management コンソール今月の請求額・請求書を見る、支払い方法を設定する画面
AWS Cost Explorerコストをグラフで分析。サービス別・月別に見る。過去の傾向から今後の予測も出せる。RI や Savings Plans のおすすめも出る
AWS Cost and Usage Report（CUR）いちばん細かい使用量・料金のデータを S3 にファイルで出力。自分で詳しく分析する用（今は「データエクスポート」機能の中の CUR 2.0）
使いすぎ防止AWS Budgets予算を決めて、こえそう・こえたらメールなどで通知。対応を自動で実行することも可能
AWS Cost Anomaly Detection機械学習で「いつもとちがう」急な料金の増え方を見つけて知らせる

コスト配分タグ

AWS のリソース（サーバーなど）にはタグという名札をつけられます。「部署=営業部」「プロジェクト=新サイト」のようなタグをコスト配分タグとして有効にすると、部署別・プロジェクト別に料金を分けて集計できます（Cost Explorer などで使える）。

🔑覚え方：「みつもり・みる・まもる」の3M

見積もり＝Pricing Calculator（電卓）／ 見る＝Cost Explorer（探検家がグラフを探検）／ 守る＝Budgets（予算の見張り番）

Calculator は「電卓」、Explorer は「探検家」、Budget は「予算」。英語の意味そのままです。

🎯試験に出るポイント
  • 「AWS に移行したらいくらかかるか見積もりたい」→ Pricing Calculator
  • 「過去のコストの傾向をグラフで見たい」「将来のコストを予測」→ Cost Explorer
  • 「予算をこえたらアラート」→ Budgets
  • 「最も詳細な請求データ」→ Cost and Usage Report
  • 「部署ごとにコストを分けたい」→ コスト配分タグ
  • 「複数アカウントの請求をまとめて、ボリューム割引」→ Organizations の一括請求
⚠️ひっかけ注意

Budgets と CloudWatch の請求アラームはどちらも「料金が〇ドルをこえたら通知」ができますが、予算管理なら Budgets が基本の答え。
Cost Explorer は見るだけ（通知はしない）、Budgets は見張って知らせる、と分けて覚えましょう。

5. サポートプラン —— 困ったときの助け

AWS で困ったとき、AWS の技術者に相談できるサポートプランがあります。

⚠️大事：2025年12月にプランの種類が新しくなりました

AWS は2025年12月にサポートプランを「Basic（無料）＋ 3つの有料プラン」に作り直すと発表しました。ただし、CLF-C02 試験の問題は昔のプラン名で出る可能性が高いので、ここでは両方説明します。昔のプラン（Developer・Business・Enterprise On-Ramp）は 2027年1月1日まで使える予定です。

試験でよく出る：昔からの5つのプラン

プランだれ向け？いちばん速い応答とくちょう
ベーシック
（Basic）		全員（無料）技術サポートなし
（請求・アカウントの問い合わせのみ）		ドキュメント、re:Post、Health Dashboard、Trusted Advisor の基本チェックのみ

🔑覚え方：応答時間は「12 → 1 → 30 → 15」

「デ・ビ・オン・エン、じゅうに・いち・さんじゅう・じゅうご」とリズムで唱えます。
そして「専任 TAM はエンタープライズだけ」「24時間の電話はビジネスから」の2つを合わせて覚えます。

AWS Trusted Advisor —— 無料のアドバイザー

AWS Trusted Advisorトラステッド アドバイザー
あなたの AWS の使い方を自動でチェックして、改善点を教えてくれる「健康診断」。
チェックする分野：コスト最適化・パフォーマンス・セキュリティ・耐障害性・サービスクォータ（上限）・運用上の優秀性
プラン使えるチェック
ベーシック・デベロッパー基本チェックだけ（サービスクォータと、一部のセキュリティチェック：S3 バケットの公開設定、MFA の設定など）
ビジネス以上全部のチェックが使える
🔑覚え方：Trusted Advisor の分野「こ・パ・セ・た・サ・う」

コスト／パフォーマンス／セキュリティ／たいしょうがい性（耐障害性）／サービスクォータ／うんよう（運用上の優秀性）
→「こっぱせた さう」（小っ恥ずかしいサウナ）と覚える。

🎯試験に出るポイント
  • 「最も安く、本番環境で24時間電話サポート」→ ビジネス
  • 「専任の TAM が必要」→ エンタープライズ（On-Ramp は TAM のチーム）
  • 「15分以内の応答」→ エンタープライズ
  • 「使っていないリソースを見つけてコスト削減のアドバイスを」→ Trusted Advisor
  • 「AWS 側の障害情報を見たい」→ AWS Health Dashboard

6. そのほかの助け

AWS Marketplaceマーケットプレイス
ほかの会社が作ったソフトウェアやサービスを探して買えるオンラインストア。料金は AWS の請求にまとめられる。
AWS Partner Network（APN）パートナー ネットワーク
AWS を使ったシステム作りを手伝ってくれるパートナー企業の集まり。コンサルティングする会社や、ソフトを作る会社がいる。
AWS re:Postリポスト
AWS の質問掲示板（Q&A コミュニティ）。だれでも無料で質問・回答できる。AWS の専門家が答えることも。
AWS Professional Servicesプロフェッショナル サービス
AWS 社員の専門家チームが、移行などの大きなプロジェクトを手伝ってくれる（有料）。
AWS IQアイキュー
AWS 認定を持つフリーランスの専門家に仕事を頼めるサービスでした。2026年5月28日でサービス終了し、今は AWS Marketplace の「プロフェッショナルサービス」が後を継いでいます。古い問題集には出てくるので、名前だけ知っておきましょう。
AWS Skill Builder / ドキュメント / ナレッジセンター
無料の学習コンテンツ（Skill Builder）、公式ドキュメント、よくある質問集（Knowledge Center）。困ったらまずここ。
こんなときだれに頼む？
無料でみんなに質問したいre:Post
ソフトを買って AWS ですぐ使いたいMarketplace
外部の会社に構築を手伝ってほしいAWS Partner Network（パートナー）
AWS 社員の専門家に大型案件を手伝ってほしいProfessional Services
AWS の技術者に障害の相談をしたいサポートプラン（ビジネス以上なら24時間）

AWS の料金の3つの基本は？ データ転送はどちら向きが有料？
コンピューティング（時間）、ストレージ（量）、データ転送。AWS から外へ出す（アウトバウンド）が有料、入れる（インバウンド）は基本無料。
2025年7月以降の新しいアカウントの無料利用枠のしくみは？
クレジット制（登録時100ドル＋試すと最大100ドル追加）。無料プラン（最大6か月 or クレジットを使い切るまで）と有料プランを選ぶ。常に無料のサービスは両方で使える。
割引が大きい順に、購入オプションを並べると？
スポット（最大約90%、中断あり）→ Savings Plans / リザーブドインスタンス（1年か3年の約束で最大約72%）→ オンデマンド（定価）。
Organizations の一括請求のメリットは？
請求書が1つにまとまる、使用量の合計でボリューム割引、RI / Savings Plans の割引をアカウント間で共有、追加料金なし。
「見積もる・見る・守る」それぞれのツールは？
見積もる＝Pricing Calculator、見る＝Cost Explorer（グラフ・予測）／CUR（いちばん細かいデータ）／Billing コンソール、守る＝Budgets（予算アラート）／Cost Anomaly Detection（異常検知）。
部署ごとに料金を分けて集計したいときは？
コスト配分タグを使う。
昔からの5つのサポートプランと、いちばん速い応答時間は？
ベーシック（技術サポートなし）、デベロッパー（12営業時間）、ビジネス（1時間）、エンタープライズ On-Ramp（30分）、エンタープライズ（15分）。
専任の TAM がつくのはどのプラン？ 24時間電話サポートは何から？
専任 TAM はエンタープライズ（On-Ramp は TAM のチーム）。24時間の電話・チャットはビジネスから。
Trusted Advisor がチェックする分野は？ 全チェックが使えるのは？
コスト最適化・パフォーマンス・セキュリティ・耐障害性・サービスクォータ・運用上の優秀性（こ・パ・セ・た・サ・う）。全チェックはビジネス以上。
re:Post・Marketplace・Professional Services のちがいは？
re:Post＝無料の Q&A コミュニティ、Marketplace＝他社のソフトを買えるストア、Professional Services＝AWS 社員の専門家チームによる有料支援。
